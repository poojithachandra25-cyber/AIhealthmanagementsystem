## Hospital Management System

## frontend
-- Create LMS website with latest version of the Angular.
-- Follow the Create the Layout page as per the image shared.
-- Use the Angular Material for the application and make sure the each and every page should be responsive.
-- Website should look professional and catchy. 
-- In the Navbar it should have Home, Our Departments , Contact and Login button.
-- Application login should have 3 roles, Patient, Doctor and Admin. 
-- Design the Login and Sign up pages accordingly. They should look professional.
